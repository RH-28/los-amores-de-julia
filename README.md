# Los Amores de Julia — Redesign Concept

A mobile-first redesign concept for the [Los Amores de Julia](https://www.losamoresdejulia.com/) Mexican bistro site (Rancho Cucamonga, CA), built to pitch to the owner.

Keeps the existing brand (mustard/teal/cream palette, heart-and-flame mark, real address/hours/phone) but rebuilds the page with:

- A working, keyboard-accessible menu-tab section (the original site's menu tabs don't function)
- A fully responsive layout — no more broken/squeezed mobile view
- A real "Reservations" button linking to their OpenTable page

## Status

This is a **pitch/demo**, not the live site. Menu items and the About section are placeholder copy — swap in real dishes, pricing, and the owner's story once confirmed.

## Preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
